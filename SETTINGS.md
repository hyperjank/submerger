# Project Settings

This file documents configuration options stored in `submerger/settings.json`.

## LLM settings

```
{
  "llm": {
    "api_key": "<your token>",
    "api_base": "http://localhost:1234/v1",
    "model": "qwen3-8b"
  }
}
```

- `api_key` – API token for the language model service.
- `api_base` – HTTP endpoint of the API.
- `model` – Model name to use.
